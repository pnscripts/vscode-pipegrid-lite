# Changelog

## 1.1.0 (2026-10-16)

- Ctrl+V of cells copied from Excel, Google Sheets or LibreOffice (tab-separated rows) inserts an aligned Markdown table on VS Code 1.97 and newer; the paste options widget switches back to plain text. Never inside fenced code blocks, for single lines or for comma text. Setting `pipegridLite.pasteSpreadsheetAsTable` (default on).
- Repository and bugs links point at `pnscripts/vscode-pipegrid-lite`; README screenshot URLs fixed (1.0.1 changes, never published separately).

## 1.0.0 (2026-10-12)

- First release of the Lite edition: Format Table, Format All Tables, Create Table and format on save, with display-width alignment for CJK text and emoji.
